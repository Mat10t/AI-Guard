# Заголовок
Runtime-проверка лимитов перед обработкой запроса

## Контекст
Перед маршрутизацией запроса шлюз должен блокировать запрос при превышении активного лимита.

## Что нужно сделать
- Добавить в gateway pre-check через `limits-service`.
- Считать токены запроса/ответа и обновлять счетчики периода.
- Блокировать запрос при превышении project или key лимита с понятной причиной.

## Связанный сервис / модуль
`limits-service` + `api-gateway`.

## Критерии готовности
- Превышение лимита гарантированно блокирует новый запрос.
- Ответ содержит понятный код/причину отказа.
- Состояние счетчиков корректно обновляется по периодам.
