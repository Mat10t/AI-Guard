# Заголовок
Регистрация организации и базовая авторизация

## Контекст
Онбординг должен проходить самостоятельно: регистрация -> вход -> доступ к защищенным разделам.

## Что нужно сделать
- Реализовать `/auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`.
- Создавать организацию и первого пользователя в одной операции.
- Выдавать JWT access + refresh в HttpOnly cookie.

## Связанный сервис / модуль
`auth-org-service`.

## Критерии готовности
- Регистрация без обязательных данных невозможна.
- После успешного login открывается доступ к защищенным API.
- Logout инвалидирует refresh-сессию.
