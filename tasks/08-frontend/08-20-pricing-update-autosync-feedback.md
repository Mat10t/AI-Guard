# Заголовок
Providers UI: feedback по автопересчету лимитов после pricing update

## Контекст
После обновления цены пользователь должен видеть итог автопересчета лимитов, иначе UX выглядит непредсказуемо.

## Что нужно сделать
- На странице `Analytics -> Providers` читать `affected_project_limits` из ответа pricing endpoint.
- Показывать явное сообщение успеха вида: “Цена обновлена. Автопересчитано N project-лимитов.”
- Сохранить текущую обработку ошибок и role guard (Admin-only edit).
