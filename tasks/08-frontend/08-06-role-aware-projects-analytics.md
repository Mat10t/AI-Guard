# Заголовок
Role-aware UX для проектов и аналитики

## Контекст
Backend уже ограничивает действия ролями. UI должен заранее показывать доступные/недоступные действия.

## Что нужно сделать
- Декодировать роль пользователя из JWT claims в frontend session-layer.
- На `/projects` скрыть или disabled действия без прав (issue/revoke key, update limits).
- На `/auth` ограничить действия invites/role-management по ролям.
- На `/analytics` ограничить действия audit/csv согласно ролям.
- Показать понятные подсказки при недоступных действиях.

`frontend`.

## Критерии готовности
- Пользователь видит только релевантные действия своей роли.
- UI не предлагает действие, которое гарантированно завершится `403`.
- Ограничения совпадают с backend RBAC-контрактами.
