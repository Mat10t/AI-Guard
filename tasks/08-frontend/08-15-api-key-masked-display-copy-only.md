# Заголовок
Маскированное отображение API-ключа в Projects

## Контекст
Сейчас в карточке проекта полный `api_key` отображается текстом, что противоречит ожидаемому UX и повышает риск случайной утечки в демонстрации.

## Что нужно сделать
- В `/projects` показывать API-ключ только в маске (`first6...last4`).
- Если полного ключа нет, но есть `prefix`, показывать `prefix...`.
- Если нет ни полного ключа, ни `prefix`, показывать `-`.
- Убрать рендер полного `api_key` из интерфейса.
- Сохранить кнопки копирования полного ключа и export-команды.
- Кнопки копирования делать активными только при наличии полного `api_key`.
- Обновить текстовые подсказки: нейтрально объяснить, что в UI ключ всегда отображается в маске.

## Критерии готовности
- В карточке проекта нет отображения полного `api_key`.
- Маска отображается стабильно для всех состояний ключа.
- Копирование полного ключа и export-команды продолжает работать при наличии `api_key`.
- Для revoked/недоступного ключа кнопки копирования недоступны и есть явное сообщение.
