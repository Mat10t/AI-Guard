# Заголовок
Delete/Revoke UX: явный результат и рефетч после destructive actions

## Контекст
После удаления/отзыва в UI сейчас не всегда понятно, что действие успешно применилось, так как изменения могут быть только локальными.

## Что нужно сделать
- Для `project delete`, `member delete`, `key revoke` после успеха выполнять рефетч соответствующего списка.
- Добавить короткий loading-state на уровне карточки/строки действия.
- Сохранить явные success/error сообщения в `Notice`.
- Исключить «тихий» клик без видимого эффекта.
