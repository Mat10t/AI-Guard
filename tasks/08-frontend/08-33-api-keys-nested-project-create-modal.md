# Заголовок
API Keys: nested project-create modal in key-create flow

## Контекст
Сейчас создание проекта реализовано inline внутри модалки ключа, что перегружает форму. Нужен двухшаговый модальный поток как в AI Studio-подобном UX.

## Что нужно сделать
- В модалке `Create API key` добавить в селект проекта option `Создать новый проект`.
- При выборе option открывать отдельную модалку `Создать проект` поверх текущей.
- После успешного создания:
  - закрывать модалку проекта;
  - возвращать пользователя в модалку ключа;
  - выставлять созданный проект выбранным.
- Удалить inline-блок `Create project inline`.
- Сохранить существующие create/copy/revoke/open usage сценарии и RBAC.
