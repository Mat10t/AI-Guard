# Заголовок
Копирование API-ключа через кнопку после обновления страницы

## Контекст
Пользователь ожидает кнопку копирования рабочего `api_key` в разделе проекта, а не только сразу после выпуска ключа.

## Что нужно сделать
- На странице `/projects` использовать `api_key` из `GET /projects/{id}/key`.
- Показывать кнопку `Скопировать API-ключ` при наличии полного ключа.
- Показывать кнопку `Скопировать export команду` для быстрого запуска скриптов.
- Обновить сообщения в UI, чтобы явно различать `api_key` и `prefix`.

## Критерии готовности
- Кнопка копирования доступна после `Статус ключа`, даже после reload страницы.
- Пользователь получает понятный feedback об успешном/неуспешном копировании.
- Интерфейс не ломает mobile-first layout.
