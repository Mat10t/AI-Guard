# Заголовок
UI проекта: бюджет и токены с автосинхронизацией

## Контекст
Настройка лимитов в проекте должна поддерживать одновременно токены и бюджет с прозрачной логикой пересчета и mobile-first UX.

## Что нужно сделать
- В разделе лимитов проекта добавить поля: `Billing model`, `Token limit`, `Budget limit (USD)`, `Period`.
- Реализовать двусторонний автопересчет по формуле 50/50 с правилом `последнее измененное поле главнее`.
- При сохранении отправлять `sync_source` в `PUT /limits/projects/{id}`.
- После сохранения обновлять draft нормализованными значениями из ответа backend.
- Загрузку текущих настроек выполнять через `GET /limits/projects/{id}`.
- Для ролей без прав на изменение оставить режим read-only/скрытие mutating действий по текущей RBAC матрице.

## Критерии готовности
- Пользователь с правами может настроить лимит проекта как через токены, так и через бюджет.
