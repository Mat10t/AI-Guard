# Заголовок
Role matrix для навигации и видимости разделов

## Контекст
Интерфейс должен строго соответствовать RBAC: пользователь видит только доступные разделы и действия.

## Что нужно сделать
- Зафиксировать матрицу ролей (Admin/PM/Dev/Finance) для разделов и действий.
- Реализовать hide sections + hide actions в меню и на страницах.
- Синхронизировать frontend-видимость с backend RBAC-конрактами.
- Исключить "пустые" или вводящие в заблуждение блоки для ролей без доступа.
- Матрица MVP:
  - Admin: все разделы и действия.
  - PM: все разделы и действия, кроме смены ролей участников.
  - Dev: `Projects` (read-only), `Analytics` (без audit/csv), без mutating действий.
  - Finance: `Analytics` (включая audit/csv), `Organization` (read-only), без mutating действий в `Projects`.

## Критерии готовности
- Навигация и страницы отображаются по ролям строго по матрице.
- Пользователь не видит разделы и действия, которые ему недоступны по роли.
- Запрещенные секции не рендерятся вообще (не только disabled-кнопки).
