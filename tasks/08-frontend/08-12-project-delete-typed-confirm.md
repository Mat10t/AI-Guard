# Заголовок
Удаление проекта в UI с подтверждением по имени

## Контекст
Backend поддерживает удаление проекта, но в кабинете отсутствует пользовательский сценарий удаления с безопасным подтверждением.

## Что нужно сделать
- Добавить в `/projects` действие удаления проекта для ролей с правом mutating (`Admin`, `PM`).
- Перед удалением требовать точный ввод имени проекта (typed confirmation).
- Вызывать `DELETE /projects/{id}` только при валидном подтверждении.
- После успеха удалять проект из локального state, очищать связанный state ключа/лимитов и показывать success notice.
- При ошибке показывать понятный error notice без тихих отказов.

## Связанный сервис / модуль
`frontend` (`/projects`).

## Критерии готовности
- Пользователь с правами может удалить проект только после корректного подтверждения имени.
- После удаления проект не отображается в списке без ручного reload.
- Пользователь без прав не видит action удаления.
- UI остается корректным в mobile-first layout.
