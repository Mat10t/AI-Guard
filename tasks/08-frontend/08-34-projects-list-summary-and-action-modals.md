# Заголовок
Projects: table summary + action modals

## Контекст
Projects-страница все еще содержит inline-формы настроек, из-за чего интерфейс выглядит перегруженным. Требуется компактный табличный формат с управлением через модальные окна.

## Что нужно сделать
- Перестроить Projects в табличный список.
- В таблице по каждой строке показывать:
  - token limit,
  - budget,
  - period,
  - fallback model.
- Убрать inline-формы настройки из основного контента страницы.
- Добавить кнопки действий на строке:
  - `Настроить лимиты`,
  - `Настроить fallback`,
  - `Удалить`.
- Каждое действие открывает отдельную модалку.
- После успешных действий делать refetch данных и показывать явный success/error notice.
