# Заголовок
Удаление участника в Organization (Admin-only)

## Контекст
Сейчас в Organization есть просмотр и приглашение участников, но отсутствует завершенный flow удаления участника с понятной обратной связью.

## Что нужно сделать
- Добавить в список участников `/auth` action удаления только для `Admin`.
- Скрывать action удаления для собственной учетной записи; показывать понятное сообщение при попытке запрещенного удаления.
- Вызывать `DELETE /org/members/{id}` и обновлять список участников после успешного удаления.
- Покрыть success/error состояния явными notice-сообщениями.
- Для ролей без прав action удаления не рендерить.

## Связанный сервис / модуль
`frontend` (`/auth`, organization/team section).

## Критерии готовности
- Admin может удалить участника из своей организации.
- Нельзя удалить самого себя через UI.
- После удаления список участников обновляется и показывает актуальное состояние.
- Для не-Admin удаление участника недоступно и не отображается.
