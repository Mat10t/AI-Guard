# Заголовок
Live-проверка статуса провайдеров с TTL-кэшем

## Контекст
Текущий `/catalog/providers/status` отражает только статус из БД и не показывает реальную доступность провайдера в момент запроса.

## Что нужно сделать
- Реализовать live-check для `openai` и `gemini`.
- Для `mock` всегда возвращать `up`.
- Добавить кэш проверок на 30 секунд.
- Добавить форс-обновление статуса по параметру `refresh=1`.
- Расширить ответ полями: `checked_at`, `latency_ms`, `error`.

## Критерии готовности
- Статус провайдера отражает live-состояние, а не только значение в БД.
- Ответ содержит метаданные последней проверки и latency.
- Форс-обновление работает через API.
