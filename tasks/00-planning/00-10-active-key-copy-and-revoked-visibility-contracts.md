# Заголовок
Active key copy + revoked visibility contracts

## Контекст
В текущем UX полный ключ копируется только сразу после create, а revoked ключи продолжают отображаться в интерфейсе. Нужно зафиксировать контракт: копирование активных ключей в любой момент и скрытие revoked из пользовательского UI.

## Что нужно сделать
- Зафиксировать контракт `GET /projects/{id}/keys`:
  - для активных ключей возвращать `api_key`;
  - для revoked возвращать `api_key: null`.
- Зафиксировать, что revoked ключи скрываются во всем frontend UI:
  - `/api-keys`,
  - key-селекторы в analytics (`usage`, `logs`, `audit`).
- Зафиксировать, что RBAC не меняется: доступ к копированию определяется текущим доступом к ключам проекта.
