# Заголовок
Scoped analytics и project assignment: контракты и матрица доступа

## Контекст
Текущая аналитика работает на org-уровне, а доступ сотрудников не ограничивается назначенными проектами. Требуется ввести scope `org/project/key` и проектные назначения сотрудников.

## Что нужно сделать
- Зафиксировать контракты scope-параметров для `usage/logs/audit/csv`.
- Зафиксировать матрицу ролей:
  - `Admin`, `Finance`: `org/project/key`;
  - `PM`, `Dev`: только `project/key`.
- Зафиксировать правило выбора `key` в UI: сначала проект, затем ключ.
- Зафиксировать invite-политику:
  - для `PM/Dev` `project_ids` обязательны,
  - для `Admin/Finance` необязательны.
