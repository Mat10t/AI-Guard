# Заголовок
Keys/Projects modal flow + AI Studio-like style contracts

## Контекст
Текущий UI API Keys и Projects работает функционально, но перегружен inline-управлением. Нужен контракт на модальные шаги для ключей/проектов и единый визуальный стиль в духе AI Studio без изменения backend-контрактов.

## Что нужно сделать
- Зафиксировать модальный сценарий создания ключа с вложенным созданием проекта:
  - в селекте проекта пункт `Создать новый проект`;
  - отдельная модалка создания проекта поверх модалки ключа;
  - после создания проекта возврат в модалку ключа с автоподстановкой нового проекта.
- Зафиксировать Projects UX:
  - табличный список;
  - видимые summary поля `token_limit`, `budget_limit_usd`, `period`, `fallback_model`;
  - actions по строке: `Настроить лимиты`, `Настроить fallback`, `Удалить`;
  - управление только через модалки.
- Зафиксировать визуальные правила (dark neutral palette, rounded/pill actions, плотная таблица) без копирования 1:1.
