# Заголовок
Системные контракты: ошибки, RBAC, лимиты, Kafka события

## Контекст
До кодирования нужен единый контракт взаимодействия сервисов, чтобы избежать расхождений в форматах ошибок, проверках ролей и событиях аналитики.

## Что нужно сделать
- Описать общий JSON-формат ошибки и коды отказов (auth, rbac, limit, route_unavailable).
- Зафиксировать RBAC-политику для ролей Admin/PM/Dev/Finance.
- Описать модель лимитов токенов за период (project/key).
- Зафиксировать payload и ключи Kafka для обязательных событий.
