# Заголовок
Git workflow: 1 задача = 1 ветка = 1 PR (enforcement)

## Контекст
Для учебной защиты нужно формально подтверждать, что каждая новая задача реализуется из отдельной ветки и вливается отдельным PR. Нужны прозрачные правила, шаблоны и базовая локальная автоматизация.

## Что нужно сделать
- Зафиксировать в репозитории правила ветвления и PR-потока для новых задач.
- Добавить PR-шаблон с обязательными полями проверки.
- Добавить локальный `commit-msg` hook для формата сообщений `<task-id>: ...` на ветках `feat/*` и `fix/*`.
- Добавить вспомогательный скрипт создания ветки из task-файла.
- Добавить документацию по branch protection для `main`.
- Добавить сервисные поля в шаблон задач, чтобы фиксировать `Branch/PR/Merged at`.

## Критерии готовности
- В репозитории есть документация и шаблоны для потока `1 задача = 1 ветка = 1 PR`.

- Локальный hook отклоняет commit в `feat/*`/`fix/*` ветках без префикса task-id.
- Есть воспроизводимый способ создать branch из task-файла.
