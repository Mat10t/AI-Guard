# Заголовок
Gateway: динамический расчет стоимости по каталогу моделей

## Контекст
Сейчас gateway считает `estimated_cost` только для `gpt-4o-mini`, что ломает аналитику расходов при расширении каталога.

## Что нужно сделать
- Убрать хардкод стоимости для одной модели.
- Рассчитывать стоимость по `provider_models` (input/output cost) для любой модели из каталога.
- Добавить безопасный fallback: если модель не найдена в каталоге, не ломать запрос и вернуть `estimated_cost = 0`.
- Логировать техническое предупреждение при расчете стоимости для неизвестной модели.
- Сохранить существующий контракт usage/audit без изменений.

## Критерии готовности
- Для `gpt-5.4-mini` и `gpt-5.4` в usage фиксируется ненулевой `estimated_cost`.
- Для неизвестной модели gateway не падает и пишет `estimated_cost = 0`.
- Публичный REST API шлюза остается совместимым.
