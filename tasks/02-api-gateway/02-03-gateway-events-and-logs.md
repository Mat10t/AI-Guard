# Заголовок
События Kafka и технические логи шлюза

## Контекст
Нужны события и техлоги для аудита, аналитики и разбора проблем интеграции.

## Что нужно сделать
- Публиковать Kafka-события request.accepted/rejected/completed/fallback.used.
- Сохранять технические логи запросов с привязкой к ключу/проекту.
- Добавить correlation id в логи и события.

## Связанный сервис / модуль
`api-gateway`.

## Критерии готовности

- Retry/fallback можно установить по журналированию.
