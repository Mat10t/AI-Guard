# Заголовок
Запись и просмотр аудита изменений

## Контекст
Нужна прозрачность административных действий: кто, что, когда изменил.

## Что нужно сделать
- Реализовать прием и хранение audit-событий.
- Реализовать API `/audit` с фильтрами по типу действия/объекту/периоду.
- Гарантировать поля actor/action/object/time в записи аудита.

## Связанный сервис / модуль
`audit-analytics-service`.

## Критерии готовности
