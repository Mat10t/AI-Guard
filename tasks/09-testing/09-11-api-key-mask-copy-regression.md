# Заголовок
Регрессия UI по маске API-ключа и копированию

## Контекст
После перехода на маскированное отображение ключа нужно зафиксировать, что UX безопасный и при этом интеграционный поток копирования ключа не сломан.

## Что нужно сделать
- Добавить frontend regression checklist для сценариев отображения ключа в Projects.
- Проверить, что после выпуска ключа UI показывает только маску и не рендерит полный `api_key`.
- Проверить копирование полного `api_key` и export-команды через существующие кнопки.
- Проверить поведение при отсутствии полного ключа (старый/revoked): кнопки disabled, понятное сообщение.
- Зафиксировать, что backend API-контракты не меняются и существующие integration/e2e сценарии остаются зелеными.
