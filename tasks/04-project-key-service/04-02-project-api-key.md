# Заголовок
Выпуск и отзыв API-ключа проекта (один ключ на проект)

## Контекст
Для интеграции нужен ключ проекта, при этом в MVP допускается только один активный ключ на проект.

## Что нужно сделать
- Реализовать выпуск ключа в карточке проекта.
- Реализовать просмотр ключа и статуса.
- Реализовать отзыв ключа с подтверждением.
- Публиковать события `api_key.created` и `api_key.revoked`.

## Связанный сервис / модуль
`project-key-service`.

## Критерии готовности
- У проекта может существовать только один ключ.
- Отозванный ключ не проходит проверку доступа в gateway.
- Статус ключа актуально отображается в API/UI.
