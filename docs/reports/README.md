# Reports for Quality & Static Analysis

Эта папка содержит отчеты для проверки quality/security части.

## Основные файлы
- `quality-latest.md` — итог последнего запуска quality/security проверок.
- `static-analysis-latest.md` — итог последнего Sonar-сканирования.

## Команды запуска
- `make quality`
- `make sonar-scan`
